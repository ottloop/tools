Introduction to image metadata

Every photo carries more information than what's visible on screen. Hidden inside the file itself is a layer of data describing the camera that took it, the settings used, when and sometimes where it was captured, and often who owns it. What is image metadata?

Image metadata is descriptive information stored inside an image file alongside the actual picture data. It can include technical details like resolution and color space, camera settings like aperture and ISO, administrative details like copyright and author, and sometimes location data from GPS. Metadata travels with the file itself, so it's still there even after the photo is renamed, moved, or shared, unless something specifically strips it out.

What is EXIF?

EXIF (Exchangeable Image File Format) is the most common metadata standard, embedded automatically by nearly every digital camera and smartphone. It typically records the camera make and model, lens used, exposure time, aperture, ISO, focal length, flash status, white balance, orientation, and the date and time the photo was taken. If location services were enabled, EXIF can also store GPS coordinates.

What is IPTC?

IPTC (International Press Telecommunications Council) metadata was originally designed for the news and publishing industry. It focuses on editorial information rather than camera settings — captions, keywords, credit lines, copyright notices, the photographer's name, and location descriptions like city or country. IPTC fields are typically added manually by a photographer or editor rather than generated automatically by a camera.

What is XMP?

XMP (Extensible Metadata Platform) is a flexible, XML-based metadata format created by Adobe. It can carry the same kind of information as EXIF and IPTC, plus custom fields defined by the software that created or edited the file. XMP is commonly added or updated by editing tools like Adobe Photoshop and Lightroom, and it's designed to be extensible so new metadata types can be added without breaking compatibility.

EXIF vs IPTC vs XMP

CAMERA-GENERATED

EXIF

Technical shooting data written automatically by the camera — exposure, lens, date, and often GPS coordinates.

EDITORIAL

IPTC

Captions, keywords, credit and copyright information typically added manually for publishing and licensing.

FLEXIBLE & EXTENSIBLE

XMP

An XML-based container that can hold EXIF-like and IPTC-like data plus custom fields from editing software.

How metadata reading works

Image files store metadata in defined segments alongside the pixel data — for example, a JPEG's APP1 segment holds EXIF and XMP blocks using a structured binary or XML format. The OTTLOOP Image Metadata Viewer parses these segments directly in your browser, decodes the individual tags, and organizes them into readable categories like camera information, exposure settings, GPS data and color profile — all without ever needing to send the file anywhere.

Camera metadata explained

Camera metadata typically includes the make and model of the camera or phone, the lens model and sometimes its serial number, and shooting settings such as aperture (f-number), shutter speed, ISO, focal length, white balance, metering mode and whether flash fired. Together these fields describe exactly how a photo was captured, which is useful for photographers reviewing their own settings or verifying how a shot was taken.

GPS metadata explained

When a camera or phone has location services enabled, it can embed the exact latitude and longitude where a photo was taken, and sometimes altitude and a GPS timestamp. The OTTLOOP viewer converts these coordinates into a direct Google Maps link when present, so you can instantly see the location on a map. Not every photo has this data — many phones let you disable location tagging, and most social platforms strip it automatically.

Why metadata matters

Metadata matters because it's a record of context that the image itself doesn't show. It helps photographers troubleshoot and refine their technique, helps buyers and journalists verify authenticity, helps archivists organize large photo collections by date or camera, and helps anyone understand exactly what they're looking at — down to the exact second and settings a photo was captured.

Benefits of reading metadata

  • Learn from your own shots — review the exact settings behind a photo you like to repeat the result.
  • Verify authenticity — camera and date information can help confirm when and how an image was created.
  • Organize collections — sort and search large photo libraries by camera, lens or date taken.
  • Check licensing details — IPTC copyright and creator fields clarify who owns an image.
  • Confirm technical specs — resolution, color profile and bit depth matter for print and professional work.
  • Spot hidden GPS data — see exactly what location information a file is carrying before you share it.

Metadata privacy risks

The same fields that make metadata useful can also be a privacy risk. GPS coordinates reveal exactly where a photo was taken — potentially your home, workplace or a child's school. Camera serial numbers and device details can sometimes be used to link photos back to a specific owner. Author and copyright fields can expose a name you didn't intend to share publicly. Before posting an image somewhere public, it's worth checking exactly what metadata it contains.

How to remove metadata

If a photo contains information you don't want to share, use a dedicated EXIF Remover tool to strip all metadata in one step, or check your image editor or operating system for a built-in "remove properties" option before exporting. Many compression and resizing tools, including OTTLOOP's own Image Compressor and Image Resizer, also offer a toggle to strip EXIF data automatically as part of the process.

Best practices

  • Check metadata before publicly sharing any photo taken with a phone, since GPS tagging is often on by default.
  • Keep original files with full metadata intact for your personal archive, and strip metadata only from copies meant for public sharing.
  • Use IPTC fields intentionally for professional or licensed work so copyright and credit information travels with the file.
  • Don't rely on file names or folder structure alone — EXIF date fields are far more reliable for organizing large photo libraries.
  • Remember that metadata can be edited or forged, so treat it as helpful context rather than absolute proof in sensitive situations.

Frequently asked questions.

Everything people ask us before checking their first image's metadata.

Is the OTTLOOP Image Metadata Viewer really free?

Yes. The OTTLOOP Image Metadata Viewer is 100% free with no hidden limits, no watermark, and no sign-up required.

What image formats can I check for metadata?

You can upload JPG, JPEG, PNG, WEBP, GIF, TIFF, BMP, AVIF, HEIC and SVG files, though the amount of metadata available depends on the format and how the file was saved.

What is EXIF data?

EXIF stands for Exchangeable Image File Format. It is metadata embedded by cameras and phones describing settings like aperture, shutter speed, ISO, focal length, date taken and sometimes GPS location.

What is the difference between EXIF, IPTC and XMP?

EXIF mainly stores camera and shooting settings, IPTC stores editorial information like captions, keywords and copyright, and XMP is a flexible format from Adobe that can carry both kinds of data plus custom fields.

Does every photo contain GPS location data?

No. GPS data is only present if the camera or phone had location services enabled at the time the photo was taken, and many platforms strip it automatically when photos are uploaded or shared.

Can I see the exact camera and lens used to take a photo?

If the EXIF data is present, the tool displays the camera make and model, lens model, and often the lens serial number under the Camera Information panel.

Why does my image show no metadata at all?

Many platforms such as social networks and messaging apps strip metadata automatically on upload, and some image editors remove it on export, so a clean file with no metadata is common and not an error.

Do you store or upload my images to a server?

No. All metadata reading happens locally in your browser, and any temporary data is cleared automatically once you close or refresh the tab.

Can I check metadata for multiple images at once?

Yes. Upload several images together and each one gets its own full metadata report on the same page.

Can I export the metadata report?

Yes. You can download the full metadata report as a TXT file, a JSON file, or a CSV file, or copy a text summary directly to your clipboard.

What is a color profile and why does it matter?

A color profile, usually an embedded ICC profile, tells software how to interpret the colors in an image so they display consistently across different screens and printers.

What does DPI mean in an image?

DPI stands for dots per inch and describes pixel density for printing. It does not affect how an image looks on a screen, only how large it prints and how sharp it appears on paper.

Is metadata a privacy risk?

It can be. GPS coordinates, device details, and sometimes author information embedded in a photo can reveal more than intended if the file is shared publicly without first removing that data.

How do I remove metadata from a photo?

You can use a dedicated EXIF Remover tool, or most image editors and even some operating systems offer a built-in option to strip metadata before sharing a file.

Will the tool add a watermark to my image?

Never. OTTLOOP does not modify, watermark, or alter your image in any way — it only reads and displays the metadata already embedded in the file.

Do I need to sign up or install anything?

No account, download or browser extension is required. Everything runs directly on this page.

Can I use this tool on mobile?

Yes, the metadata viewer is fully responsive and works on phones and tablets, including pasting images from your clipboard.

What does the Google Maps link next to GPS data do?

When GPS coordinates are found in a photo, OTTLOOP generates a direct Google Maps link so you can see exactly where the picture was taken.

Can I search for a specific metadata field?

Yes. Use the search box above the metadata panel to instantly filter every category down to fields matching your search term.

Is this tool accurate for all cameras and phones?

The tool reads whatever metadata a file actually contains using standard EXIF, IPTC and XMP parsing, so accuracy depends entirely on what the originating camera, phone or software embedded in the file.
